# M34A-11 — Migrate C17 to typed generation

- Status: in-progress
- Depends on: M34A-10

## Goal

Prove that the architecture handles declarators, header/source placement,
explicit ownership, cleanup, and function-table polymorphism without raw C.

## Baseline and decisions (2026-09-08)

Java closes at 3840536 after a clean fresh review and all eight hosted jobs.
C starts with a partial legacy emitter, mutable public layouts and raw runtime
files. Existing support diagnostics are not evidence that all 42 capabilities
already work. The registered target ID remains org.polyrust.c; C17 is its
language version. The detailed C layer specs define an opaque owning ABI and
explicitly scope what generated-code verification can promise about foreign C
callers. No Java-specific grammar, GC policy or JVM budgets are copied.

## Definition of done

- C owns all type/declarator, expression, statement, declaration/definition,
  initializer, linkage, file/package, and grammar/format enums in its
  specification.
- Every admitted feature has an exhaustive typed C strategy; monomorphized
  aggregate identities and known C callables are typed and collision-safe.
- The verifier proves sequencing, UB-free arithmetic/shifts, union-tag
  dominance, pointer constness/ownership, initialization, and exactly-once
  cleanup on every exit path.
- Flat owning interface handles use typed context/vtable construction plus
  clone/move/drop operations; multiple conformance, nested interface values,
  dispatch, allocation failure, and explicit delegation pass.
- Headers/sources, forward declarations, typedef/tag order, linkage, includes,
  helpers, and cleanup functions are resolver-derived.
- The C17 post-link checker alone constructs the opaque render-ready package;
  runtime declarations/definitions are C AST and a total structural renderer
  accepts only that certificate.
- Executable templates, raw/token/source escapes, and string/wildcard grammar
  dispatch are absent; every checker-accepted corpus case compiles as C17.
- `CCode`, runtime C/header source constants/includes, manual include/helper
  attachment, macro semantic shortcuts, and the legacy C generator are deleted.
- The C17 compliance row moves to **Pass** with exact evidence.
