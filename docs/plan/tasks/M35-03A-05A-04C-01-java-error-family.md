## Contract and implementation

Add a distinct checked local family profile with the existing three nominal
roles: sealed Outcome, canonical primitive-int Success record, and immutable Error
enum. Bind each of the six authenticated semantic kinds to its exact registered
enum constant. Descriptive selections cannot grant certification, provenance or
import authority. Keep the earlier payload-free record family API unchanged.

Use the existing typed enum declarations, registered values and interface edges.
Extend only the syntax rules needed for a constant-only enum to implement an
empty synthesized sealed interface; no inheritance, custom constant bodies,
unverified method conformance or arbitrary text escape. Validate both unresolved
and independently reconstructed resolved syntax. Existing generated bytes stay
unchanged. Reuse the exact canonical success-constructor check without weakening
it or duplicating its semantics.

Keep family checking, fixture construction and native proof in focused modules.
Give the new external proof its own Bazel target and lint coverage.

## Definition of done and tests

- Safe publication derives an opaque local-family witness only from a certified
  package with exact distinct types, permits, public members and six selected
  registered enum constants. No missing/repeated/foreign/substituted role passes.
- Reject the old empty Error record, extra constants, custom enum members,
  changed success storage/constructor, wrong implements/permits edges and
  mismatched origins. Compile-fail tests protect private witness construction.
- Strict Java21 compilation and normal/interpreted execution preserve six
  distinct enum values and success zero/negative/extreme values. Independent
  expected-value assertions and compiling wrong-kind/wrong-value controls prove

- Export the actual generated example to an ignored directory. Preserve all
  recorded prior outputs and protected WIP; full Linux Bazel release/lint,
  independent review and scoped commit/push precede completion.

This is a local target representation, not a canonical owner, dependency API or
Rust compiler witness. No ordinal-based serialization or unsafe Rust inspection.
