# M26-02 — Migrate all target plugins

- Status: complete

## Goal

Move import ownership from language files into the flat translated units for
Rust, TypeScript, JavaScript, Python, Go, Java, C++, and C.

## Definition of done

- No concrete backend calls a file-level `require_import` method.
- Each generated, runtime, test, conformance, and negative-test unit declares
  only the imports it uses.
- Conditional declaration/type/test mappings attach their dependencies to the
  same unit as their translated syntax.
- Generated bytes change only where an existing import bug is corrected.

## Tests

- Run every backend unit-test target.
- For each target family, compare empty and feature-bearing programs and prove
  conditional imports appear only in the feature-bearing file.
- Run all native, conformance, public-consumer, ABI, and sanitizer targets.
